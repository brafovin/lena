# ✨ Meine Charakter

Eine interaktive Web-App, mit der du deine **Lieblingscharaktere aus Serien und Filmen** nach deinen eigenen Vorstellungen neu erschaffen kannst.

## 🎮 Features

- **🎨 Charakter-Editor** mit Live-Vorschau (SVG-Avatar, verändert sich sofort)
  - Hautfarbe, Haarfarbe & Frisur (kurz, lang, lockig, Glatze, Mohawk)
  - Augenfarbe, Gesichtsausdruck, Outfit-Farbe
  - Accessoires: 🤓 Brille, 🎩 Hut, 🦸 Umhang, ⚡ Narbe, 🥷 Maske
  - Farbiger Hintergrund (Farbverläufe)
- **📝 Steckbrief**: Name, Universum (Harry Potter, Marvel, Star Wars …), Alter, Superkraft, Persönlichkeitsmerkmale, Hintergrundgeschichte
- **💡 Inspiration**: Vorgefertigte Steckbriefe (Hogwarts-Schülerin, Jedi, Feuermagier …) als Startpunkt – dann frei anpassen
- **🖼️ Galerie**: Alle Charaktere werden lokal gespeichert (`localStorage`), können angesehen, bearbeitet und gelöscht werden
- **🎲 Zufalls-Charakter** für schnelle Ideen
- **📱 Responsive Design** – funktioniert auf Handy, Tablet und Desktop

## 🚀 Starten

Einfach `index.html` im Browser öffnen – keine Installation, kein Build nötig.

```bash
# z. B. mit einem lokalen Server
python3 -m http.server 8000
# dann: http://localhost:8000
```

## 📁 Dateien

- `styles.css` – Design
